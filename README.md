# 听见进步 · 我的王陆语料库

个人雅思听写练习页面，部署目标：[ielts-wanglu-dictation.github.io](https://ielts-wanglu-dictation.github.io/)。

完整保留上游的 **5,873 个词条、32 个小节、第 3 / 4 / 5 / 11 章**，包含英文、音标、中文释义和原始顺序。上游 README 中“8 个章节”的说法与实际语料不符，此处以原始数据为准。

## 功能

- 整节 / 20 / 50 / 100 词分组、自选词序范围、顺序和乱序听写。
- 行内播放、F2 重听、Enter 下一题、自动发音、连播、英美口音、语速、重复、间隔和语音选择。
- 本机英语语音优先，在线词典及备用发音；支持短语、缩写和原语料注释的发音归一化。
- 答案错位修正：插入空行、答案上移、撤销。插入时保护已有末题答案。
- 检查答案、再次修改、提交后重新批改。检查不重复计入错词或历史。
- 错词 / 全部批改、历史详情、正确率趋势、整组或错词重练。
- 每日目标、连续练习统计、当前设备当地日期统计。
- 错词搜索、按小节筛选 / 分组、按错误次数或最近时间排序；全部、到期、巩固中和已掌握筛选。
- 间隔复习：答对依次安排 1 / 3 / 7 / 14 / 30 / 60 天后复习，错误立即回到待复习。连续答对 3 次标记已掌握，仍会按时到期。
- 自动保存草稿并续练、浅色 / 深色主题、手机布局和键盘操作。
- JSON 完整备份与恢复，兼容原版 `{hist, wb}` / `wl2_*` / `wl3_*`；导入先校验再确认，替换前下载当前备份。
- 错词 CSV 导出；页面和语料离线缓存、Web App 安装入口由浏览器提供。

## 使用

首页点击“开始今日练习”，或在“语料练习”选择小节与范围。建议先使用设置页“测试语音”。所有练习答案、错词和偏好保存在当前浏览器的 `localStorage`，不会自动跨设备同步。可定期导出 JSON，在另一台设备导入。

原生语音取决于设备所安装的英语语音。在线发音会向 DictionaryAPI / Youdao / Google 等服务发送当前英文词条，不发送你的答案和学习记录。这些免费服务可能受网络、限流和浏览器播放策略影响。此页面不包含原书配套录音。

首次联网打开后缓存页面和词库。离线语音仍需本机英语语音支持。浏览器可能回收网站缓存或存储，重要记录请备份。无账号系统、后端或密钥。

## 本地运行与验证

需要 Node.js 22+ 和 Python 3；运行时无 npm 依赖。

```sh
npm test
npm run check
python -m http.server 4173 --bind 127.0.0.1
```

在浏览器打开 `http://127.0.0.1:4173`。请通过 HTTP 使用，ES modules 与 Service Worker 不支持直接双击 HTML 的 `file://` 模式。

GitHub Pages 自动部署见 [DEPLOYMENT.md](DEPLOYMENT.md)。应用为相对路径的纯静态页面，可部署在域名根路径或项目子路径。

## 文件

`app.js` 界面与练习流程；`core.js` 批改 / 统计 / 备份 / 复习纯函数；`audio.js` 发音；`data.js` 完整语料；`styles.css` 响应式样式；`sw.js` 离线缓存；`tests/` 核心功能测试。生产构建自动根据全部资源生成缓存版本，无需手动修改版本；直接预览源码时可清除本地测试缓存后刷新。
